Once per installation, about 10 minutes. Any Microsoft account can register the app, with no paid Azure subscription; the account that matters is the one you sign in with at step 2, whose OneDrive gets the invoices. Use a new registration for this app rather than reusing one made for something else.

  1. Open the Microsoft Entra admin center (Identity → Applications → App registrations) and choose New registration.
  2. Name: anything, e.g. teslamate-expenses.
  3. Supported account types: Personal Microsoft accounts only (“any organizational directory and personal Microsoft accounts” also works).
  4. Redirect URI: choose the platform Web and enter exactly this address, then Register: {{ callback_url }} It must match character for character. Microsoft only accepts http:// for localhost.
  5. Authentication: leave Allow public client flows at No (the default). With it on, Microsoft treats the app as a public client and every later sign-in refresh fails with AADSTS90023: Public clients can't send a client secret.
  6. API permissions (optional): Add a permission → Microsoft Graph → Delegated permissions, tick Files.ReadWrite and offline_access. Skip it and you're asked to consent to the same two when you connect.
  7. Certificates & secrets → Client secrets → New client secret. Copy its Value straight away. It's shown only once, and the Secret ID beside it is not the secret. Secrets last at most 24 months: note the Expires date for the box below.
  8. From Overview, copy the Application (client) ID (not secret).
  9. Paste both here and save, then press Connect OneDrive.
